Sketched user interface skeletons. Procedurally generated with p5.brush.skeleton. It’s my pleasure to share that shinygenui is now on CRAN. It brings generative UI to Shiny: the developer defines a catalog of components, and a language model builds and updates an interface as users describe what they need.
You can install it with:
install.packages(&quot;shinygenui&quot;) Or get the development version from GitHub:
