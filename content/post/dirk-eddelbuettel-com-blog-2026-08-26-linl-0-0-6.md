 <p>A new release of our <a
href="https://github.com/eddelbuettel/linl">linl package</a> for writing
LaTeX letters with (R)markdown is now on CRAN. <a
href="https://github.com/eddelbuettel/linl">linl</a> makes it easy to
write letters in markdown, with some extra bells and whistles thanks to
some cleverness chiefly by <a
href="http://aaronwolen.com/">Aaron</a>.</p>
<p>This version is mostly maintenance: updates to the continuous
integration setup, as well as updates to packaging including use of
Authors@R in DESCRIPTION. No functional changes, no new code, or new
features.</p>
